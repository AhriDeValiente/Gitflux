✨ Key Features

🚀

One-Command Deploy

Stage, commit, pull with rebase, and push in a single command. Works on the current branch and never force-pushes.

💾

Back Up All Repos

Back up all your GitHub repositories to a local folder in parallel (up to 4 jobs at a time).

⏪

Undo Anything

Undo a commit, restore a file, or reset everything — with a safety confirmation.

🔄

Daemon Auto-Sync

Auto-sync every N seconds with a per-repo lock (start/stop/status/restart) so it never runs twice.

🔒

Strict Input Validation

Control characters are rejected; branch/tag names go through git check-ref-format; URLs must be https/ssh/git@. Commit messages stay flexible.

🛡️

Sensitive-File Guard

Files like .env, *.pem, *.key, and SSH keys trigger a warning before commit and are refused for gists.

🖥️

Adaptive Help

Fits your terminal width, uses a pager, supports NO_COLOR, and can be opened by section: gitflux help github.

🌐

Bilingual (EN/ID)

English by default, Indonesian on demand. Switch with export GITFLUX_LANG=id.

About Gitflux

Gitflux is a GitHub CLI assistant built for Termux and Linux users who want to automate everyday Git operations without having to memorize dozens of commands. A great fit for mobile developers who manage GitHub repositories directly from an Android device. It also runs on macOS, and partially on Windows (Git Bash / MSYS2 / Cygwin).

Who is it for?

  • Developers working in Termux / Android
  • Linux and macOS users who want a faster Git workflow
  • Beginners who want to learn Git with simple commands

📋 Changelog

  • NEW Adaptive help: fits the terminal width, uses a less pager, supports NO_COLOR, has help sections (gitflux help <section>), and a GITFLUX_NOPAGER option.
  • NEW Sensitive-file detection (.env, *.pem, *.key, SSH keys, etc.) when staging, and refusal when creating gists.
  • IMPROVED Input validation is now strict and type-specific: control characters, branch/tag names (git check-ref-format), commit revisions, URLs (https/ssh/git@), numbers, and IDs. Characters like $ are still fine in commit messages.
  • IMPROVED deploy, push, pull, and sync only run on the current branch, require origin, and refuse to run while a rebase/merge is in progress.
  • IMPROVED The daemon now has start|stop|status|restart subcommands, a per-repo lock (stale locks are cleaned up automatically), and runs non-interactively.
  • IMPROVED config set uses a key allowlist and a --local option; keygen won't overwrite an existing key unless --force is used (the old key is backed up); remote URLs are masked in output.
  • IMPROVED squash validates the commit count and requires a clean working tree; reset hard requires an explicit target; merge supports --no-ff / --squash; clone supports --depth / --branch; webhook retries up to 3 times.
  • FIX fail() now writes to stderr so errors don't mix with stdout; cmd_init uses git -C instead of cd in a subshell.

⚡ Quick Install

curl -sL https://raw.githubusercontent.com/AhriDeValiente/Gitflux/main/Gitflux.sh -o $PREFIX/bin/gitflux && chmod +x $PREFIX/bin/gitflux && gitflux setup

Then type gitflux help to see all commands.

On Linux/macOS without $PREFIX, replace $PREFIX/bin with /usr/local/bin and use sudo. gitflux setup installs git, gh, curl, and openssh.
